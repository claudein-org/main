# ClaudeIn

**Your Claude Code is now a social media manager.**

ClaudeIn turns a plain text file into a live publishing dashboard. Posts live in `claudein.yml` next to your code — write them yourself, or let Claude Code draft them. One command opens a browser preview; one click publishes.

## Who it's for

Developers and technical founders who want to stay active on LinkedIn without leaving their editor.

## How it works

```bash
cin start
```

ClaudeIn watches your project folder and streams updates to the browser in real time. Edit `claudein.yml`, save, and the dashboard refreshes instantly.

- **Text posts** — write it in YAML, publish to LinkedIn, Instagram, Facebook, or YouTube
- **Articles** — point to a `.md` file in `articles/`, ClaudeIn renders the preview
- **Media** — attach an image or video from `media/`

## Why a file?

A file is something you, your editor, and your agent can all share. Posts are versioned right alongside the work they're about — no lock-in, no copy-paste, no context switch.
